# Tannarx (2-bosqich) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xarajatlarni aktivda Order Detail bo'yicha yig'ish, yetkazishda COGS va draft Sales Invoice.
**Architecture:** `tannarx.py` — umumiy `sync_source_costs(source_doc, lines)` (JE + "Tannarx Harakati" jurnali, eski yozuvlarni bekor qilib qayta yozadi), `deliver_kz_transit(doc)` / `undo_delivery(doc)`. Har bir manba doctype o'z qatorlarini (`lines`) tuzib shu funksiyani chaqiradi.
**Tech Stack:** Frappe/ERPNext v15. **Spec:** `docs/superpowers/specs/2026-11-18-tannarx-design.md`

## Global Constraints
- Kompaniya valyutasi bo'yicha JE: `debit`/`credit` kompaniya valyutasida, hisob valyutasi `kassa.get_account_currency_amount` bilan.
- Jurnal summasi kompaniya valyutasida; qoldiqlar jurnaldan hisoblanadi.
- Tonna: WI/KZL — Ombor Harakati `tonna`; Peregruz — `fakt_transload / quantity × net_weight / 1000`.

## Interfaces
- `tannarx.CostLine = dict(order_detail, kategoriya, wip_account, expense_account, amount (hujjat valyutasida), kz_fura=None)`
- `tannarx.sync_source_costs(doc, lines, currency, credit_account, posting_date)` → JE nomi yoki None.
- `tannarx.cancel_source_costs(doctype, name)`.
- `tannarx.allocate_by_tonnage(total, tonnage_by_od: dict) -> dict`.
- `tannarx.received_tonnage(order_detail)`, `tannarx.delivered_tonnage(order_detail)`.
- `tannarx.deliver_kz_transit(doc)`, `tannarx.undo_delivery(doc)`.
- `tannarx.create_fura_purchase_invoices(source_doc, order_details)`.
